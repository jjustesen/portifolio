# Ideia base do portfólio

Eu montaria o portfólio como uma experiência curta, mas com conteúdo suficiente para provar senioridade. A animação seria a introdução; o conteúdo precisa fechar a venda.

## 1. Hero

Objetivo: dizer quem você é em 5 segundos.

```
JOHANNES JUSTESEN
Frontend Engineer

AI PRODUCTS / INTERACTION / SYSTEMS

Building interfaces for machines that think,
stream, predict and respond.

Norway / EU · Available for selected work · 6+ years
```

CTAs:

```
VIEW SELECTED WORK →
DOWNLOAD CV →
```

## 2. Manifesto / introdução

Após a primeira transição, uma frase curta que define seu posicionamento.

```
I build the interface layer between
complex systems and human intuition.
```

Texto de apoio:

```
My work sits where product thinking, frontend architecture,
real-time data and interaction design meet.
```

## 3. Selected work

Use 3 projetos fortes, não uma lista longa. Cada projeto deve ter contexto, impacto e responsabilidade.

Estrutura por projeto:

```
PROJECT 01 / ENTERPRISE AI

AURAMIND

An enterprise generative AI platform designed for
complex workflows, streaming responses and model exploration.

ROLE
Senior Frontend Developer / Sole frontend engineer

STACK
React · TypeScript · Amazon Bedrock · AWS

WHAT I OWNED
Frontend architecture, component system, streaming UX,
model configuration interfaces and interaction analytics.

OUTCOME
Turned complex AI capabilities into a coherent interface
for real product teams.
```

Se houver números reais, inclua:

```
Reduced time to first usable response by X%
Used by X teams
Shipped across X client environments
```

Outros dois projetos podem seguir o mesmo formato:

```
PROJECT 02 / DESIGN SYSTEM
A scalable component platform for multi-product teams.

PROJECT 03 / INTERACTIVE SYSTEMS
Experimental interfaces exploring real-time input,
motion and generative behavior.
```

## 4. Como você trabalha

Essa seção dá confiança para quem quer contratar você.

```
FROM COMPLEXITY TO CLARITY

01 — Understand the system
I map constraints, users, data flows and product goals
before deciding what the interface should become.

02 — Build the interaction model
I translate invisible system behavior into feedback,
states, motion and clear decision points.

03 — Engineer for change
I create frontend systems that remain understandable
when the product, team and technical scope grow.
```

## 6. Experiência

Uma linha do tempo breve, focada em escopo e evolução.

```
2024 — 2026
Senior Frontend Developer
Enterprise generative AI platform

2022 — 2024
Frontend Engineer
Product interfaces, scalable systems and interaction work

Earlier
Web development, creative technology and visual experimentation
```

Use os cargos, empresas e datas exatos do CV aqui.

## 8. Perspectiva pessoal

O conteúdo pode humanizar sem virar uma biografia longa.

```
Before software, there was photography.

Different craft, same instincts:
composition, light, rhythm and knowing what to leave out.
```

Se fotografia for relevante no seu CV ou trabalho, inclua 3 imagens autorais pequenas aqui.

## 9. Depoimentos ou prova social

Só inclua se houver frases reais de clientes, líderes ou colegas.

```
“Johannes combines strong engineering judgment with
an unusually sharp eye for interaction.”

Name · Role · Company
```

Duas citações curtas já bastam.
